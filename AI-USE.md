# AI use log

This file lists every use of AI tools that is recorded for this project. The Claude Code part was generated by a
script from the session logs on the first author's computer (Claude Code stores every session as a log file). A
model response is one answer of the model, often a single tool call; it counts toward this project when its
working folder was the course folder or when it read, wrote or ran something there. The counts are therefore a
lower bound: answers given without touching the project's files are not counted. The Antigravity and review rows
come from that tool's own records and from the review's reports.

*Effort* is Claude Code's reasoning-effort setting for a response (medium < high < xhigh < max): how much the
model may think before it answers.

## What the authors did

The authors set the goals, made the design decisions, chose the experiments, reviewed and approved every change,
and gave the presentations. No AI tool is an author.

## How the outputs were checked

- 34 automated tests: perft counts, two independent move generators, alpha-beta equal to minimax, and the faster
  engine returning the same moves, values and node counts as the presented one on 386 positions.
- Every result comes from a run of the code and is logged under `project/experiments/`; the supplementary tables
  are generated from those files by a script, and the paper's numbers were checked against them.
- Reference details and claims taken from sources were checked against the original documents.
